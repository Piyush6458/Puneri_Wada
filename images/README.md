## Image Guidelines

1. **Format**: Use JPEG for photographs
2. **Optimization**: Compress images for web (aim for under 200KB per image)
3. **Aspect Ratios**: 
   - Hero/Headers: 16:9 or wider
   - Content images: 4:3 or 3:2
4. **Quality**: High resolution but web-optimized
5. **Content**: 
   - Traditional Puneri wada architecture
   - Wooden pillars and carved doors
   - Courtyard (chowk) views
   - Rural surroundings
   - Pre-wedding and ad shoot examples
   - Sinhagad Fort views
